# TangentAtlas.Web

The Tangent Atlas website, www.tangentatlas.com: the landing page, sign-up and sign-in (through Microsoft Entra External ID), and the signed-in pages. ASP.NET Core 10 with Blazor server-side rendering, deployed to Azure App Service on Linux by `.github/workflows/deploy-production.yml` on every push to `main`.

The ledger behind the product is [TangentAtlas.LedgerService](https://github.com/tangent-atlas/TangentAtlas.LedgerService), generated by [Bellerophon](https://github.com/bellerophon-dotnet/bellerophon).

## Running it

```
dotnet test
dotnet run --project src/TangentAtlas.Web --launch-profile https
```

Sign-in needs the external tenant's two identifiers (`IdentityProvider:Authority`, `IdentityProvider:ClientId`); without them the public pages work and nobody can sign in.
